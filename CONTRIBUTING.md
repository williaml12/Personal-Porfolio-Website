# Contributing to Personal Portfolio Website

Thank you for your interest in contributing to my personal portfolio site! 🎉

Since this project represents my personal work, contributions will be reviewed carefully — but I do welcome feedback, improvements, and ideas. If you notice a bug, accessibility issue, or think of a cool new feature, feel free to contribute!

## How You Can Contribute
- Fix bugs (typos, broken links, display issues)
- Improve responsiveness and layout
- Suggest or improve animations and interactions
- Optimize SEO
- Improve accessibility (ARIA roles, contrast, alt text)
- Suggest project structure or content improvements

## Getting Started
1. **Fork the repository**
2. **Clone your fork**
```
git clone https://github.com/YOUR_USERNAME/Personal-Porfolio-Website.git
cd Personal-Porfolio-Website
```
3. **Create a new branch**
```
git checkout -b your-feature-branch
```
4. **Make your changes**
5. **Commit your changes**
```
git commit -m "Description of changes"
```
6. **Push to your fork**
```
git push origin your-feature-branch
```
7. **Submit a Pull Request (PR)** — include a short description of what you changed and why

## Style Guidelines
- Keep HTML, CSS, and JavaScript well-organized and commented
- Match the style and structure of the existing code
- Keep the portfolio simple and elegant (avoid unnecessary bloat)

## Code of Conduct
Please be respectful and professional in all communications and contributions.
